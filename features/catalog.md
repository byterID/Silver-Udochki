# 📦 Каталог

Каталог состоит из трёх уровней: **раздел → категория → позиция**.
Сейчас в нём 4 раздела, 36 категорий и 542 позиции.

## Источник данных

Данные лежат в `database/data/catalog.php`, загружает их `CatalogSeeder`. Запись товара:
`['Название', ['теги'], цена]`, а для вариантов — `['Название', ['теги'], ['вариант' => цена]]`.
Каждый вариант становится отдельной позицией с артикулом `SU-<sku>-NNN`.

## Загрузка и перенос

```bash
# перезалить каталог из database/data/catalog.php
docker compose exec app php artisan db:seed --class=CatalogSeeder --force

# снять дамп текущего каталога в database/dumps/catalog.sql
sh docker/db/catalog-dump.sh

# развернуть каталог из дампа (миграции должны быть применены)
sh docker/db/catalog-restore.sh
```

Для Windows рядом лежат `.ps1`-версии дампа и восстановления.

> ⚠️ Сидер и восстановление из дампа **полностью перезаписывают** разделы, категории и товары
> (`TRUNCATE ... CASCADE`). Привязки товаров к акциям (`promotion_product`) стираются вместе с ними:
> сами акции остаются, товары в них нужно выбрать заново. На продакшене сидер вручную не запускают,
> там каталог переносится дампом.

Строки заказов и журнал склада хранят `product_id` без внешнего ключа, поэтому перезапись
каталога их не затрагивает: название, артикул и цена копируются в них на момент покупки.

## Витрина

- Поиск по каталогу ограничен 60 запросами в минуту.
- Реплики продавца берутся из `config/shop.php`.
- «Монитор каталога» и карточки получают данные из `ShopCatalog`: единая форма товара для карточек, монитора и корзины.
